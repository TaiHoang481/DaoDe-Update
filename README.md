# DaoDe-Update

Repository công khai chỉ dùng để phát hành cập nhật DaoDe.

- `version.json`: phiên bản mới nhất, URL tải và ghi chú.
- GitHub Pages: phục vụ `version.json` cho các máy đang chạy DaoDe.
- GitHub Releases: chứa file `DaoDe_X.Y.Z.zip`.

Không đưa mã nguồn, `keygen.py`, khóa riêng hoặc dữ liệu nhạy cảm vào repository này.
